# Worlds26 · Predicción de eliminatorias de Worlds 2026

Sitio estático (un solo `index.html` más la carpeta `logos/`), sin dependencias ni paso de build.

- **Cuadro:** el cuadro predicho y el campeón, en dos modos: por porcentaje y por confianza (Pick'Em).
- **Detalle:** el razonamiento y las probabilidades de cada partido, más todos los cruces posibles.
- **Análisis:** los datos, el modelo Elo y el consenso con ChatGPT y Gemini.

## Ver en local
Abre `index.html` en el navegador.

## Desplegar en Render
1. Sube esta carpeta a GitHub.
2. En Render: **New → Static Site** y elige el repositorio.
3. Branch: `main`. Build Command: vacío. Publish Directory: `.`
4. **Deploy Static Site**.

O usa **New → Blueprint** con el `render.yaml` incluido.

Los logos pertenecen a sus respectivos equipos y se usan solo con fines informativos.
